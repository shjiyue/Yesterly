# Yesterly

**专注工作，少写日报。**

Yesterly 是面向 macOS 与 Windows 的 AI 工作记录与报告工具（英文品牌名；中文界面产品名为「极简日报」）。照常工作，让它按你设定的方式采集电脑上的工作画面，把零散线索整理成本地时间线，再根据真实记录生成日报、周报、月报、年报或自定义报告。

产品围绕两件事展开：**记录工作，生成报告**。从一天结束时反复回想「今天做了什么」，变成先回看记录、核对材料，再整理成可以使用的总结。

## Yesterly 能做什么

### 1. 把工作过程整理成记录

- **定时记录**：按设定间隔采集画面，积累工作线索。
- **回车触发**：可选开启回车记录，连续触发会合并处理。
- **自定义快捷键**：需要留下某个工作节点时，手动触发采集。
- **多显示器选择**：选择参与记录的显示器范围。
- **画面去重与空闲跳过**：减少重复记录；鼠标持续不动达到设定时长后，跳过本轮自动触发，手动快捷键仍可使用。
- **开始与暂停**：按工作需要控制记录状态与采集频率。

应用通过画面中可见的内容和前台窗口信息整理工作摘要。回车监听用于触发采集，不保存逐字键盘输入；显示在屏幕上的内容仍可能进入截图。

### 2. 在本地时间线回看与修订

- 按日期和时间范围回看工作记录。
- 查看摘要、补充说明、修订或删除记录，让材料更贴近实际工作。
- 查看记录分布、统计与活动热力图，辅助回顾不同时间段的工作线索。

统计反映的是记录分布，不等同于精确工时或工作绩效。是否完成某项任务，仍应以实际工作结果为准。

### 3. 从记录生成多种工作报告

- 支持日报、周报、月报、年报与自定义报告。
- 选择报告时段，在生成前预览来源材料。
- 使用内置模板，也可以创建、修改和复用本地模板。
- 补充写作要求，让报告更符合项目、团队或个人表达习惯。
- 生成后继续修订，在历史报告中回看，并复制内容或导出 **TXT / Markdown**。

AI 生成内容应在使用前核对，尤其是完成状态、数字、结果和后续计划。

### 4. 记录模型与报告模型分别配置

| 使用场景 | 可选方式 | 说明 |
| --- | --- | --- |
| 识别工作画面 | Yesterly 订阅模型、自定义 API、第三方授权模型 | 记录模型需要具备适用的视觉识别能力；自带模型需完成相应测试并启用 |
| 报告直接输出 | 自定义 API、第三方授权模型 | 在「报告模型」中单独配置、测试并启用 |
| 报告网页输出 | DeepSeek 网页 | 将准备好的附件与提示词交给网页生成，并将结果保存回本地 |

**Yesterly 订阅提供的记录模型不用于报告直接输出。** 使用直接输出前，请先配置报告模型；也可以选择 DeepSeek 网页方式。第三方模型、授权与网页服务的可用性和额度以对应服务商账号为准。

支持将兼容的本地模型服务配置为自定义模型地址。若希望工作内容在本机处理，需要同时为记录和报告配置本机模型，并使用报告直接输出；账号、设备授权和订阅验证仍需联网。

### 5. 管理截图与本地备份

- 截图默认不长期保留：仅为识别任务临时存储，任务结束后删除，文字记录保留。
- 可按需开启截图保留，以便后续查看或重新识别，并设置保留天数与空间上限。
- 提供本地加密备份与恢复，备份包含工作记录、报告、模板和截图。
- 备份不包含登录状态和模型授权；恢复需要备份密码与原账号，模型授权需重新配置。

## 第一次使用

1. **安装并登录**：启动客户端，按提示在浏览器中完成注册或登录与桌面授权。
2. **确认账号权益**：在账号页面查看体验或订阅状态，具体额度与价格以官网和客户端实际显示为准。
3. **授予采集权限**：macOS 需允许屏幕录制；使用回车记录时，按提示授予对应权限。
4. **选择记录模型**：使用订阅模型，或配置并测试自定义 API / 第三方授权模型。
5. **设置记录方式**：选择显示器、采集间隔，以及是否启用回车和快捷键触发。
6. **积累并核对记录**：正常工作，在时间线中查看、补充或修订摘要。
7. **生成报告**：选择报告类型、时段、模板与输出方式，预览来源后生成，核对并导出。

每次启动应用默认尝试开始记录，需通过登录、权益、模型与系统权限检查；手动暂停仅对本次运行生效。处理不希望被采集的内容前，请先暂停记录。

## 数据与隐私

**工作资料本地保存，模型处理范围由你选择。**

| 数据或操作 | 处理方式 |
| --- | --- |
| 工作摘要、时间线、报告和修订版本 | 保存在当前设备，不提供工作内容云同步 |
| 截图识别 | 画面与识别提示直接发送至所选模型服务；使用本机模型时由本机服务处理 |
| 报告直接输出 | 所选时段文字材料、模板和要求发送至配置的报告模型 |
| DeepSeek 网页输出 | 报告附件与提示词进入 DeepSeek 网页及对应会话 |
| 账号与订阅 | 云端处理登录、设备授权、权益、订单与必要的用量信息 |

「本地保存」不等于所有处理都离线完成。使用云端模型时，工作材料会发往相应服务商；模型请求不通过产品服务器中转工作内容。第三方服务的数据处理方式以其规则为准。

登录同一账号不会自动同步另一台设备的工作记录。更换设备前请先完成备份。删除本地记录，也不会撤回已经发送给第三方模型或网页的材料，或自动删除已导出的文件和备份。

完整说明见[官网隐私说明](https://jijianribao.qitingai.com/zh/privacy)和客户端「隐私说明」。

## 常见问题

### 这是开源项目吗？

本仓库仅公开产品介绍、版本说明和安装包，不发布产品源代码，也不作为开源代码仓库维护。下载客户端不需要克隆仓库或安装开发环境。

### 为什么开始记录后没有内容？

依次检查登录与权益状态、记录是否暂停、所选模型是否可用，以及系统录屏权限是否已经授予。鼠标空闲跳过或画面重复也可能使本轮没有新增记录。可在「偏好设置 → 程序日志」查看具体原因。

### 为什么不能直接生成报告？

记录模型与报告模型独立配置。请到「报告模型」中配置、测试并启用自定义 API 或第三方授权模型，或改用 DeepSeek 网页输出。

### 使用自己的模型还需要账号和权益吗？

需要。账号、设备授权与权益验证适用于客户端的记录和报告流程；使用自带模型不等于绕过产品权益。模型服务商自身的费用与限制也由对应服务商确定。

### 能完全离线使用吗？

客户端的登录、设备授权与订阅验证仍需联网。配置本机模型可以让工作内容在本机处理，但不代表整个产品完全离线。

### 如何升级？

在客户端「偏好设置 → 版本更新」中检查更新，或直接打开[最新 Release](https://github.com/shjiyue/Yesterly/releases/latest)，下载对应平台的安装包。升级前建议备份重要资料。

### 如何反馈问题？

可通过客户端侧栏「客服」联系，也可以在本仓库 [Issues](https://github.com/shjiyue/Yesterly/issues) 提交问题。请说明系统、芯片架构、客户端版本、复现步骤与错误提示；公开反馈前移除密钥、登录信息及不希望公开的工作内容。
